How to Play

💣
One random player starts holding the bomb. Whoever holds it when the timer hits zero loses a life!
🏃
Run up and touch another player to pass the bomb to them. You can't pass it straight back to whoever just passed it to you.
❤️
Everyone starts with 3 lives. Lose all 3 and you're eliminated — but you can keep spectating.
⚡
Grab glowing power-ups: Speed Boost, Shield, Invisibility, Freeze, Teleport and Magnet each change the game in a different way.
🎮
Desktop: WASD or Arrow Keys to move. Mobile: use the joystick in the bottom-left.
🏆
Last player standing wins the round!
